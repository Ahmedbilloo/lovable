# Ahmed's Insight Hub

Create a modern, minimal personal portfolio website for a Business Analytics professional named Ahmed Billoo.

The purpose of the website is to showcase projects, technical skills, and professional experience in a clean and impactful way. The design should be professional, minimal, and optimized for recruiters and hiring managers.

Website Structure:

Hero Section:

Display name: "Ahmed Billoo"

Tagline: "Business Analytics Professional"

Short 2-line introduction highlighting analytics, data-driven decision making, and experience in pharmaceutical distribution

Include buttons: "View Projects", "Download Resume", "Contact Me"

About Section:

M.S. in Business Analytics graduate with 4+ years of experience applying analytics to pharmaceutical distribution

and supply chain operations. Experienced in using SQL, Python, Tableau, Power BI, and R to build interactive

dashboards, demand forecasting models, and predictive analytics solutions that improve operational decision-

making.

Projects Section (Main Focus):

Display 3–5 projects in a card layout

Each project should include:

Title

Business problem

Approach

Tools used

And a code section to display the code for the model/project. 

Key results/impact

Highlight flagship project: "Inventory Optimization & Demand Forecasting Dashboard"

Forecasting using ARIMA

Tableau dashboards for sales and inventory insights

SQL Server integration

Focus on reducing stockouts and improving planning

Skills Section: Present skills in a clean bullet format:

• Programming: Python, R • Data Analysis: SQL, Excel (Pivot Tables, VLOOKUP), Pandas, NumPy • Visualization: Tableau, Power BI, Matplotlib, ggplot2 • Machine Learning: Scikit-learn, Random Forest, Decision Trees, KNN, Naive Bayes, Neural Networks • Statistical Methods: Regression, Hypothesis Testing, Time Series Analysis

Experience Section:

Include Jawed Traders (Pharmaceutical Distribution)

Focus on:

Supplier management (GSK, Pfizer, Abbott)

Operations and distribution

Data-driven reporting improvements

Dashboard / Portfolio Section:

Showcase Tableau dashboards (screenshots or embeds)

Contact Section:

Email

LinkedIn

Contact form

Design Requirements:

Minimal, modern UI

Clean typography

Card-based layout for projects

Responsive design

Smooth scrolling

Subtle hover effects only

Tone:

Professional and straightforward

No generic or overly wordy content

Focus on clarity and real work

Goal: Create a clean, high-impact portfolio that quickly shows skills, projects, and real business understanding.
